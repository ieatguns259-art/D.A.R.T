D.A.R.T is a voice assistant for Windows. It requires an API key for its AI provider.
To test: launch the app, click the floating circle, open Settings > General,
paste an api key into "API Key" and click Save.
Say "Dart, what time is it" (a microphone is needed), or open the text chat
from the Settings window and type instead.
The app runs as a full-trust desktop application (runFullTrust) because it
controls the local PC on the user's request: launching apps, adjusting volume,
taking screenshots and reading the clipboard.
